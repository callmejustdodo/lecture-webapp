# 강의용 웹앱 One Pager (초안)

> 상태: 초안 v3 · 작성일 2026-11-25
> `❓` 표시는 아직 정하지 않은 항목입니다.

## 1. 한 줄 요약

AI·Claude 활용 강의를 **결제부터 수강까지 한곳에서** 할 수 있는 웹앱입니다. 수강생은 결제하고 로그인해서 강의자료와 녹화본을 보며 진도를 관리하고, 강사(나)는 자료를 올리고 수강 현황을 봅니다.

## 2. 문제

- 강의자료가 슬라이드, 노션, 깃헙, 카톡 공지 등 여러 곳에 흩어져 있다. ❓
- 결제, 수강생 명단 관리, 자료 접근 권한 부여, 환불을 따로따로 손으로 한다. 한 기수 100명 이상이면 감당하기 어렵다. ❓
- 수강생이 실습을 따라오다 막혀도 강사가 어디서 막혔는지 알기 어렵다. ❓
- 프롬프트, 설정 파일, 명령어를 복사해 쓰는 일이 많은데 자료 형태가 이를 돕지 못한다. ❓
- 유료 녹화본이 링크 공유나 다운로드로 유출될 수 있다. ❓

## 3. 대상 사용자

| 사용자 | 하는 일 |
|---|---|
| 강사 (나) | 강의·챕터 구성, 자료 작성, 녹화본 업로드, 수강생·결제 현황 확인 |
| 수강생 | 결제, 자료 열람, 실습 따라 하기, 녹화본 다시 보기, 진도 체크, 환불 신청 |

- 강의 형태: 라이브(오프라인/온라인)로 진행하고, 끝난 뒤 녹화본을 올린다.
- 자료 공개 범위: 로그인한 수강생만 볼 수 있다. 강의 소개 페이지만 공개한다.
- 규모: 한 기수 100명 이상
- 수강 기간: 기간 제한이 있다. ❓ 기수 종료 후 몇 개월
- 질문 채널: 외부 채널을 쓰고 앱에는 링크만 둔다. ❓ 디스코드 / 카톡 오픈채팅 / 슬랙

## 4. 핵심 기능 (MVP)

1. **강의 소개 페이지 (공개)**: 커리큘럼, 일정, 가격, 결제 버튼
2. **결제 → 수강 등록**: 국내 카드·간편결제로 결제하면 해당 강의 접근 권한이 자동으로 생긴다.
3. **환불 자동 처리**: 수강생이 앱에서 신청하면 환불 규정에 따라 금액을 계산해 환불하고 권한을 회수한다. ❓ 환불 규정
4. **로그인**: ❓ 이메일 매직링크 / 구글 / 카카오
5. **강의 → 챕터 → 레슨 자료 페이지**: 마크다운으로 작성하고, 코드·프롬프트 블록에 복사 버튼을 둔다.
6. **녹화본 보기 (DRM + 워터마크)**: 수강생만 재생할 수 있고, 다운로드를 막으며, 화면에 수강생 식별 워터마크를 띄운다.
7. **수강 기간 만료**: 기간이 끝나면 자료와 녹화본 접근이 닫힌다.
8. **진도 체크**: 레슨 완료 표시, 강사용 현황판

나중에 고려할 것: 레슨별 질문/댓글, 과제 제출, 퀴즈, 수료증, 쿠폰, 수강 기간 연장 결제, AI 조교(Claude 기반 Q&A)

## 5. 하지 않을 것 (Non-goals)

- 다른 강사가 가입해서 쓰는 멀티 강사 플랫폼
- 앱 안에서의 라이브 스트리밍 (라이브는 줌 등 외부 도구를 쓴다) ❓
- 앱 안의 질문 게시판·채팅 (외부 채널 사용)
- 해외 결제
- 구독형 요금제 (강의 단위 1회 결제만) ❓

## 6. 성공 기준

- 첫 기수의 결제, 등록, 자료 배포, 환불을 100% 이 앱으로 진행한다.
- 개강일에 100명 이상이 동시에 접속해도 결제와 영상 재생에 문제가 없다.
- ❓ 예: 수강생 완강률, 레슨별 이탈 지점을 확인할 수 있다.
- ❓ 예: 강의 1회분 자료를 올리는 데 걸리는 시간

## 7. 일정

2027년 1월 중 개강이 목표이며, 남은 기간은 약 6~8주다. ❓ 정확한 개강일

| 단계 | 내용 | 기간(가안) |
|---|---|---|
| 0 | PG 가입·심사 신청, DRM 영상 서비스 선정 | 즉시 (개발과 병행) |
| 1 | 자료 페이지 + 로그인 + 접근 권한·수강 기간 | 2주 |
| 2 | 결제 → 자동 등록, 소개 페이지 | 2주 |
| 3 | DRM 녹화본 재생, 진도 체크, 강사 현황판 | 2주 |
| 4 | 환불 자동 처리 | 1주 |
| 5 | 실제 자료 입력, 결제·환불 리허설 | 1주 |

### 일정 위험

위 가안은 합계 8주로, 여유가 없다. 범위를 키우는 항목은 두 가지다.

- **DRM + 워터마크**: 직접 만들기 어렵고 유료 영상 서비스를 써야 한다. 서비스 선정과 비용 확인이 먼저 필요하다.
- **환불 자동 처리**: 부분 환불 계산, 권한 회수, 결제사 연동 오류 처리까지 필요하다.

일정이 밀리면 줄일 순서: ① 환불을 수동 처리로 (첫 기수만) → ② DRM을 "로그인한 수강생만 재생 + 워터마크"로 낮춤 → ③ 강사 현황판을 단순 목록으로. 녹화본은 개강 후에 올라오므로 단계 3의 영상 부분은 개강 직후로 미룰 수도 있다.

## 8. 기술 방향 (가안)

- Next.js (App Router) + Vercel 배포
- 자료는 저장소 안의 마크다운(MDX)으로 관리해 깃으로 버전 관리한다.
- 인증 + DB(수강생, 등록, 수강 기간, 진도, 결제·환불 기록): ❓
- 결제: 국내 PG 연동 (사업자 등록 있음). ❓ PG사 선정
- 영상: DRM과 수강생별 워터마크를 지원하는 영상 호스팅 서비스. ❓ 서비스 선정, 예상 비용

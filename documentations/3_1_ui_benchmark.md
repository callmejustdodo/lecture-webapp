## 조사 범위와 한계

대상: 패스트캠퍼스, 클래스101, 탈잉, 라이브클래스, 아마겟돈 클래스(amag-class.com).

- 공개된 페이지와 가이드 문서만 읽었다. 로그인, 가입, 결제는 하지 않았다.
- 그래서 **결제 단계 화면과 로그인 뒤 화면(강의실, 플레이어, 관리자 콘솔)은 직접 보지 못했다.** 라이브클래스는 공개된 운영자·수강생 가이드로 대부분 확인했고, 나머지는 2차 자료이거나 확인하지 못했다.
- 조사 시점이 블랙프라이데이 기간이라 타이머와 할인 표기가 평소보다 많았을 수 있다.
- 아래에서 "확인 못 함"은 없다는 뜻이 아니라 보지 못했다는 뜻이다.

## 2. 공통 패턴

다섯 곳 대부분에서 반복되는 구성이다. 사용자가 이미 익숙하므로 따르는 편이 안전하다.

1. **상세 페이지는 긴 본문 + 구매 버튼 상시 노출.** 데스크톱은 우측에 따라오는 구매 카드(클래스101, 탈잉, 라이브클래스, 아마겟돈) 또는 하단 고정 바(패스트캠퍼스), 모바일은 하단 고정 바(패스트캠퍼스, 탈잉).
2. **본문 위에 앵커 탭.** 소개 / 커리큘럼 / 강사 / 리뷰 / 질문 순서가 많고, 스크롤해도 탭이 붙어 있다.
3. **커리큘럼은 아코디언.** 섹션별 강의 수와 시간을 요약하고 맛보기 영상을 섞는다(탈잉).
4. **가격은 정가 취소선 + 할인율 + 월 할부 환산가.** 환산가를 가장 크게 쓰는 곳이 많다.
5. **카카오 로그인이 맨 위.** 모든 곳이 카카오를 첫 번째 버튼으로 둔다.
6. **흰 배경, 단일 강조색, Pretendard 서체.**
7. **환불은 구간제.** "초기 전액 → 1/3 경과 전 2/3 → 1/2 경과 전 1/2 → 이후 불가" 형태로 수렴한다. PRD의 "구간제" 방식과 같다.
8. **강의실은 플레이어 옆에 커리큘럼, 아래에 자료**(라이브클래스, 클래스101).

## 4. DoClass가 다르게 가는 것

다른 곳의 약점이거나 비어 있는 부분이다. DoClass의 차별점이 된다.

| 차별점 | 다른 곳의 상황 | DoClass |
|---|---|---|
| **수강생 셀프 환불** | 대부분 고객센터나 카카오톡 채널로 요청한다. 클래스101은 환불 지연 불만이 있다 | 결제 내역에서 예상 환불액을 보고 바로 신청 (US-S-12) |
| **환불 규정을 날짜로** | 규정이 긴 글로 적혀 있거나 본문 이미지 안에 있다. 라이브클래스는 전용 영역이 없다 | 상세와 결제 화면에 "[날짜]까지 전액"처럼 계산된 표로 표시 |
| **텍스트 레슨 + 복사 버튼** | 라이브클래스에는 텍스트 레슨 유형이 없다. 클래스101은 수업노트가 부실해 자막을 받아 적었다는 리뷰가 있다 | 마크다운 레슨이 기본, 프롬프트와 명령어에 복사 버튼 (LEARN-2, 3) |
| **앱 안 라이브** | 라이브클래스는 Zoom 연동이라 강사의 Zoom 계정이 필요하고, 링크로 직접 들어가면 출석이 안 잡힌다 | 브라우저에서 바로 송출, 입장이 곧 출석 (LIVE-2) |
| **녹화본 자동 등록** | 라이브클래스는 녹화본을 따로 올려야 하는 것으로 보인다 | 라이브 종료 후 같은 레슨에 자동으로 붙음 (LIVE-6) |
| **레슨별 질문, 강사 자동 지정** | 패스트캠퍼스는 별도 게시판이라 누구에게 묻는지 불명확하다는 불만이 있다. 클래스101은 질문이 유료 코칭권이다 | 레슨에 붙은 질문 게시판, 답변 알림톡 (QNA) |
| **DRM + 워터마크** | 확인된 곳이 없다 | 녹화본과 라이브에 적용 (VOD-2, 3) |

## 6. 기획에 영향을 주는 제안

벤치마크에서 나왔지만 PRD와 다르거나 PRD에 없는 내용이다. 결정이 필요하다.

- [ ] **후기(리뷰)**: PRD는 후기를 범위 밖에 두었다. 조사한 곳은 모두 후기를 쓰고, 클래스101과 탈잉은 본문 맨 위에 둔다. 첫 기수에는 후기가 없으니 나중에 넣어도 되지만, 상세 페이지에 자리를 잡아 둘지 정해야 한다.
- [ ] **판매 조건(얼리버드 등)**: 라이브클래스는 한 강의에 판매 조건 카드를 여러 개 둔다(가격, 판매 기간, 수량). PRD는 강의당 가격이 하나다. 얼리버드 가격이 필요한가?
- [ ] **휴대폰 번호를 받는 시점**: PRD는 가입할 때 받는다(AUTH-2, 가정). 가입 단계를 줄이려면 첫 결제 화면에서 받는 방법이 있다. 라이브클래스도 결제 화면에서 받는다.
- [ ] **자동 완료 기준**: PRD는 90% 시청(가정)이다. 클래스101은 80%, 라이브클래스는 최대 시청 지점 기준이다. 80%로 낮출 것인가?
- [ ] **라이브 출석을 진도에 넣을지**: 라이브클래스는 라이브 진도율을 출석률로 계산한다. PRD의 진도는 레슨 완료만 센다.
- [ ] **월 할부 환산가 표시**: 고가 강의라면 "월 N원(12개월 할부 시)" 보조 표기가 흔하다. 쓸 것인가?
- [ ] **완주 장치**: 탈잉의 미션·장학금, 클래스101의 캘린더·연속 학습 표시 같은 장치를 둘 것인가? 서비스 이름이 "직접 하는 클래스"이므로 실습 완료 체크와 잘 맞는다.
- [ ] **알림톡 템플릿 심사 기간**: 라이브클래스 가이드는 직접 만든 템플릿의 카카오 심사에 영업일 최대 7일이 걸린다고 적는다. 1월 개강 전에 템플릿을 확정해 신청해야 한다.
- [ ] **강조색**: 조사한 곳은 붉은 핑크, 주황, 코랄, 블루, 민트를 쓴다. 목업은 지금 인디고 블루다. DoClass의 색을 정해야 한다.
